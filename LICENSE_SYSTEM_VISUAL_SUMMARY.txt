  LICENSE VALIDATION (MT5 EA):

    MT5 EA Starts
         ↓
    Calls: POST /api/licenses/validate
         ├─ License Key: LB-M1-9C8E7F2A-20260227
         └─ MT5 Account: 12345678
         ↓
    Server Validates
         ├─ ✓ Key exists?
         ├─ ✓ MT5 matches?
         ├─ ✓ Not expired?
         └─ ✓ Is active?
         ↓
    Returns: { valid: true/false }
         ↓
    EA Enables/Disables Trading


┌──────────────────────────────────────────────────────────────────────────────┐
│                          🔑 LICENSE KEY FORMAT                               │
└──────────────────────────────────────────────────────────────────────────────┘

    LB-M1-9C8E7F2A-20260227
    │  │  │        │
    │  │  │        └─ Expiry Date (YYYYMMDD)
    │  │  │           • 00000000 = Lifetime
    │  │  │           • 20260227 = Feb 27, 2026
    │  │  │
    │  │  └────────── Unique Hash (8 characters)
    │  │              • Cryptographically generated
    │  │              • Includes secret salt
    │  │              • Tamper-proof
    │  │
    │  └───────────── License Type
    │                 • W1 = Weekly (7 days)
    │                 • M1 = Monthly (30 days)
    │                 • M3 = 3 Months (90 days)
    │                 • M6 = 6 Months (180 days)
    │                 • Y1 = Yearly (365 days)
    │                 • LT = Lifetime (forever)
    │
    └──────────────── Brand Prefix (LB = License Brand)

┌──────────────────────────────────────────────────────────────────────────────┐
│                          📊 API ENDPOINTS                                    │
└──────────────────────────────────────────────────────────────────────────────┘

  PUBLIC:
    POST   /api/licenses/validate ........... Validate license (MT5 EA)

  USER (Requires Auth):
    GET    /api/licenses/my-licenses ........ Get user's licenses
    GET    /api/licenses/:key ............... Get license details
    POST   /api/licenses/:key/resend-email .. Resend license email

  ADMIN (Requires Admin Auth):
    POST   /api/licenses/generate ........... Generate new license
    POST   /api/licenses/:key/regenerate .... Change MT5 account
    POST   /api/licenses/:key/extend ........ Extend expiry
    POST   /api/licenses/:key/revoke ........ Deactivate license
    GET    /api/licenses/admin/all .......... List all licenses
    GET    /api/licenses/admin/statistics ... Get analytics
