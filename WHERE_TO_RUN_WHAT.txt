┌──────────────────────────────────────────────────────────────────────────────┐
│  🐛 TROUBLESHOOTING                                                          │
└──────────────────────────────────────────────────────────────────────────────┘

  "node: command not found"
    → Install Node.js from https://nodejs.org
    → Restart terminal after installation
  
  "Cannot find module"
    → Run: npm install
    → Make sure you're in project root folder
  
  "LICENSE_SECRET_SALT not set"
    → Check .env file has the line
    → Check Railway Variables has the variable
    → Restart server after adding
  
  "Table does not exist"
    → Run: node setup-license-tables.js
    → Or create tables manually in Supabase
  
  "Supabase connection error"
    → Check SUPABASE_URL in .env
    → Check SUPABASE_KEY in .env
    → Verify Supabase project is active
