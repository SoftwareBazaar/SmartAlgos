# Add Volatility Pivots TradingView Indicator

## What This Is

A free TradingView indicator that identifies high-probability market turning points by combining multiple technical factors.

## How to Add It

### Step 1: Run SQL in Supabase

1. Go to Supabase Dashboard: https://supabase.com/dashboard
2. Select your project
3. Click "SQL Editor" in the left sidebar
4. Click "New Query"
5. Copy and paste the contents of `add-volatility-pivots-utility.sql`
6. Click "Run" or press `Ctrl+Enter`

### Step 2: Verify It Was Added

The SQL will automatically verify the utility was added. You should see output like:

```
id | name                              | category  | price | is_free | is_active | download_url
---+-----------------------------------+-----------+-------+---------+-----------+-------------
 X | Volatility Pivots by SmartAlgos  | indicator | 0     | true    | true      | https://...
```

### Step 3: Check on Your Website

1. Go to: https://smartalgosts.com/utilities
2. You should see the new "Volatility Pivots by SmartAlgos" utility
3. It will be marked as FREE
4. Users can click to access the TradingView indicator
