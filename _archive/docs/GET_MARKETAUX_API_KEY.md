# Get Your Free Marketaux API Key (Optional)

Marketaux provides financial news and sentiment data.

## Quick Steps:

1. **Go to**: https://www.marketaux.com/
2. **Click**: "Get API Key" or "Sign Up"
3. **Create Account**: Free tier available
4. **Copy API Key**: From dashboard
5. **Update .env**: Add `MARKETAUX_API_KEY=your_key_here`

## Free Tier:

- ✅ 100 requests per day
- ✅ Financial news articles
- ✅ Market sentiment data
- ✅ News for specific symbols

## Is This Required?

**NO** - Marketaux is optional. Your app works fine without it.

- News will use fallback data
- Economic calendar still works
- Market analysis still functions

**You can skip this if you don't need news integration!**
