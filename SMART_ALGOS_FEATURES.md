## 🎯 **API Endpoints Available**

### **Authentication**
- `POST /api/auth/register` - User registration
- `POST /api/auth/login` - User login
- `GET /api/auth/me` - Get current user
- `POST /api/auth/logout` - User logout

### **EA Marketplace**
- `GET /api/eas` - Browse EAs
- `GET /api/eas/:id` - Get EA details
- `POST /api/eas` - Create EA (Admin)
- `PUT /api/eas/:id` - Update EA (Admin)

### **Subscriptions**
- `POST /api/subscriptions` - Create subscription
- `GET /api/subscriptions` - Get user subscriptions
- `GET /api/subscriptions/:id/files` - Get download files
- `POST /api/subscriptions/:id/download` - Record download

### **Payments**
- `POST /api/payments/initialize` - Initialize payment
- `POST /api/payments/verify` - Verify payment
- `GET /api/payments/history` - Payment history

### **Market Data**
- `GET /api/markets/prices` - Get market prices
- `GET /api/markets/symbols` - Get trading symbols
- `GET /api/markets/analysis` - Market analysis

### **HFT Trading**
- `GET /api/hft` - Browse HFT bots
- `POST /api/hft/:id/subscribe` - Subscribe to HFT bot
- `GET /api/hft/performance` - Performance data

### **Signals**
- `GET /api/signals` - Get trading signals
- `POST /api/signals/subscribe` - Subscribe to signals
- `GET /api/signals/performance` - Signal performance
